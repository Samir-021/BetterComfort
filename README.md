# 📍 BetterComfort

A location-based web application that helps users discover nearby hotels and restaurants with real-time guidance, reviews, and booking features.

---

## 🚀 Features

- Real-time location-based hotel & restaurant search
- View details (location, contact, reviews, ratings)
- Save favorites for quick access
- Hotel booking system (check-in, check-out, guests)
- Review and rating system
- Integration with external API (Geoapify)
- Local database support for custom entries

---

- View details and locations

## 📄 Description

BetterComfort combines location-based services with user interaction features to enhance travel and dining experiences. It integrates real-time API data with local database entries to provide accurate, flexible, and user-centric results.
